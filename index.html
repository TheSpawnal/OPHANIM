What Ophanim is

Ophanim is a defensive security sentinel that watches over a single machine. It captures the host's live traffic, attributes every flow to the process behind it, deceives intruders with honeypots and decoys, contains threats on its own ground, and writes down everything it sees as structured, replayable evidence.

It does not attack. The line between watching and striking is held by design: offense and any counter-action belong to a separate system, Cerberus, to which Ophanim hands a clean incident packet. Everything the sentinel produces is evidence you could show to anyone.

The sentinel today

The first eyes are open. What runs now on the workstation is SENSE and INTERFACE on the event spine: a minimal traffic and process monitor that already does the one thing most tools skip.

Ophanim captures the host's live traffic and keeps a flow table, dissecting every frame with each field length-guarded. It scans the process table and the open sockets, then makes the join that matters: it attributes every flow to the process and the binary behind it. The console answers which program is talking to that address, not merely that traffic exists.

On every change that counts, a new process, a new listening port, a fresh outbound connection, it writes a normalised event to an append-only log that is owner-only and greppable. The live view shows the attributed flows, the listening ports with their owners, the busiest processes, a rolling feed of events, and a footer of load, memory, and thermals.

It is built small on purpose: no network listener, no web server, standard library only, so there is little supply chain to trust. Three properties are already law in the code. Every input is treated as hostile, malformed frames counted and dropped. Privilege is dropped to the minimum the work needs. The evidence is append-only.

sudo python -m ophanim monitor

    The eight eyes

    The sentinel's work divides into eight subsystems on one event spine, an append-only record that every part reads from and writes to. Two eyes are open today; the rest are being forged.

    When something moves

    A hostile act does not trip a reflex. It travels the spine, gathering judgment at each turn, until the sentinel holds a verdict worth acting on.

      And there the watch ends. Cerberus sits downstream, weapons cold, holding for that packet. Ophanim never strikes. It delivers the signed verdict, and the hunter waits for the word before it moves.

      The discipline

      Full of eyes.

      Watch every surface. Telemetry arrives from the network, the process table, the filesystem, and the logs at once, and is normalised into a single stream before anything judges it.

      A wheel within a wheel.

      Defense is layered and nested. A small, auditable sensor core holds privilege; the heavy analysis runs apart, unprivileged, reading only the evidence the core has already written down.

      It did not turn as it went.

      Respond in any direction without hesitation, and treat every input as hostile until proven otherwise. Malformed frames are counted and dropped; no attacker gets to choose the path.

      The spirit was in the wheels.

      The local model reads text an attacker may have written: log lines, payloads, filenames. That text could try to manipulate the model itself. So the model is kept to advice only. A containment step fires from a fixed rule or your confirmation, never because the model was talked into it.
